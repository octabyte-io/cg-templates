vBulletin is long-running commercial forum software, sold as a licence to run on your own server or as a hosted cloud plan.

People look for an alternative because vBulletin costs money for a licence or a monthly plan, and some want forum software whose code they can read and change. phpBB is free, open-source forum software that has run classic boards since 2000, with regular updates in its 3.3 line and no licence fee.
