Stagetimer is a hosted, remote-controlled countdown timer for live events: you run timers from one device while presenters see a fullscreen countdown on another, with messages to the stage and a rundown of timers.

Event teams look for an alternative because Stagetimer's free plan allows three timers and three connections, and more timers, connections and its API need a paid licence. Ontime gives presenters the same countdowns and messages and adds a full run of show, delays and cuesheets for the crew, all on your own server with no limits. It shares one password across the crew rather than personal accounts.
