moving: |
  OneUptime is the only app here that imports from Pingdom: give it a read-only Pingdom API token and it brings over your checks, though not their history or alert contacts. Add your email server first, and a Twilio account if you want calls and texts.

  Uptime Kuma, Checkmate, Peekaping, Gatus, Tianji, SolidPing and CheckCle have no import from Pingdom. In Uptime Kuma, adding a monitor takes seconds: paste the address, choose how often to check, and pick who gets alerted. Checkmate works the same way: create the admin account, add a monitor for each Pingdom check, and enter your email account's sending details if you want email alerts or team invitations. In Peekaping, create the admin account, set up alert channels, then add a monitor for each check; to check from more places, run its small checker program on a machine in another region. In Gatus, add an entry for each check to its settings file in the Cloudgate console, with the conditions it must meet. Tianji works like Uptime Kuma: add each monitor with its address and check interval. In SolidPing, add a check for each Pingdom check, set up your on-call rota, and enter your email account's sending details for email alerts. In CheckCle, sign in with admin@example.com and the password Cloudgate created, and change that email to your own under Settings, User Management, then add each check as a service; install its regional agent on a server elsewhere to check from there too. Set up your alert channels first, such as email, Slack or Telegram. Run whichever app you choose on a different server from the sites it watches, so it can still alert you when they go down.

Pingdom, from SolarWinds, monitors whether websites are up and how fast they load, with checks from locations around the world, transaction checks and real-user monitoring.

Teams look for an alternative because Pingdom is priced by the number of checks, so watching every site, API and service gets expensive, and many only need to know quickly when something is down. A self-hosted Uptime Kuma checks as many services as you like, as often as every 20 seconds, with no price per check. Checkmate does the same and adds incident history, page-speed scores, server metrics and logins for the whole team. Gatus also has no price per check, and builds a status page from checks you set in one text file, and Tianji adds visitor stats and server health to the same checks. Peekaping, still in beta, has an API for everything and can check from several locations with small checkers on other machines. SolidPing adds incidents, on-call rotas and status pages on a small server. CheckCle adds server health, SSL expiry warnings and status pages to its checks, with regional agents for other locations. OneUptime imports your Pingdom checks and adds on-call paging and status pages, on a much bigger server.
