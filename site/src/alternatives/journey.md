Journey is a diary app for Android, iPhone, Mac, Windows, Chrome OS, Linux and the web. Entries sync through Journey Cloud Sync with end-to-end encryption, and a paid membership unlocks the full set of features.

People look for an alternative because the membership is a recurring cost and the diary lives in Journey's cloud. DailyTxT keeps a daily diary with photos, tags, search and a map on your own server, encrypted with each person's own key, and has no membership. It is a simpler, web-only tool, so it suits people who mostly write at a computer or in a phone's browser.
