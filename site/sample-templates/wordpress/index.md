WordPress is the most widely used way to build a website. It runs everything from one-page sites for a local café to large online shops and news sites. You pick a theme for the design, then add pages, blog posts and images with a visual editor.

Plugins add almost any feature you can think of: contact forms, online shops with WooCommerce, appointment booking, newsletters, translations and search engine tools. A hairdresser, for example, could have a site with a price list, a gallery, online booking and a blog, without writing any code.

Cloudgate installs WordPress on a server you connect and gives it a secure web address. The first person to open it chooses the site's name and creates the admin account. You can later point your own domain name at it, invite editors, and import posts from Blogger, Medium, Squarespace and other platforms.
