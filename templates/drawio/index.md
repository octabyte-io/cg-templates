Self-hosted draw.io is a free, open-source diagram editor that runs in your web browser, for drawing flowcharts, org charts, network diagrams and process maps instead of paying for Microsoft Visio or Lucidchart. You drag shapes from large libraries onto the page, connect them with arrows and style them, or start from one of its many templates.

There are no accounts and nothing is stored on the server: each diagram is saved as a file on your own computer, and you can export it as an image or a PDF. draw.io also opens Visio .vsdx files and Lucidchart diagrams, so old work is not lost. A bakery, for example, could map how a custom cake order moves from enquiry to pickup, then print the chart for the kitchen wall.

Be aware of the limits. People cannot edit the same diagram at the same time, anyone with the address can use the editor, and the makers of draw.io call this server version a test version, with a paid production version available.
