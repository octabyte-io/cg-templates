HedgeDoc is a self-hosted collaborative Markdown editor: a free, open-source alternative to HackMD, where several people write the same note in real time and share it with a link. You type on one side and see the formatted note on the other, with headings, checklists, tables, diagrams and maths.

Notes are quick to start and easy to share. Each note's owner decides who can read or edit it, can publish a tidy read-only page, and can present the note as slides. Every change is kept, so an earlier version is always a click away. A small agency, for example, could open one note for each client call, let everyone add to the agenda and action points during the meeting, then send the client the published link.

HedgeDoc works in any browser on a computer, tablet or phone. You can download notes as Markdown or HTML files and paste images straight into them. It grew out of HackMD's open-source edition, so HackMD users will find it familiar; it is a good fit for meeting notes rather than a full wiki like Notion.

Cloudgate installs HedgeDoc on a server Cloudgate provides or one you connect, together with the database it needs, and gives it a secure web address. Register your account first, then share the address with your team.
