Self-hosted TeamMapper is a free, open-source mind map tool that your team edits together in real time, shared by a link, as an alternative to MindMeister or Coggle. You start a map, add ideas as nodes, and send a link or QR code: a view-only link for people who should follow along, or an edit link for people who should help build it. Nobody has to sign up.

Nodes can have colours, pictures and web links, and a finished map exports as a PDF, an image or a file you can import again later. A bakery team, for example, could plan a new seasonal menu in one shared map during a meeting, with each person adding dishes and suppliers from their own laptop, then print the result as a PDF.

Be aware of the trade-offs. There are no accounts, so anyone with the edit link can change the map, and maps nobody has changed for a set number of days (30 unless you choose more at setup) are deleted. There is no import from MindMeister or Coggle and no phone app. Cloudgate is not connected with TeamMapper; the name belongs to its makers.

Cloudgate installs TeamMapper on a server Cloudgate provides or one you connect and gives it a secure web address. Open it and start mapping.
