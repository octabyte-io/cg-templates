faq:
  - q: Is OmniTools free?
    a: Yes, OmniTools is free and open source under the MIT licence, with no paid edition, no accounts and no task limits. You pay only for a very small server.
  - q: Is OmniTools a good alternative to iLovePDF or Smallpdf?
    a: Partly. OmniTools covers the basic PDF jobs, such as merging, splitting, compressing, rotating, password-protecting and turning PDFs into images, without uploading your files or limiting tasks. It has no Word or Excel conversion, no OCR for scanned PDFs and no e-signatures, so for regular PDF work Stirling PDF is the better self-hosted choice.
  - q: Are my files uploaded when I use OmniTools?
    a: No, OmniTools processes files in your own web browser, so they stay on your device and never reach the server. The server only hands out the web pages, and the tools contain no analytics or tracking scripts.
  - q: Does OmniTools work offline?
    a: Not fully. A few tools, such as reading text from images, image compression and some PDF tools, download their engine from public websites the first time you use them, so the browser needs an internet connection. Your files still stay on your device.
  - q: Do I need an account to use OmniTools?
    a: No, OmniTools has no accounts, no sign-in and no admin. Anyone who has the web address can use the tools, which is useful for sharing with a team, but it means you should share the address only with people who should use it.
  - q: What server size do I need for OmniTools?
    a: The smallest server is enough, because the server only serves the web pages. The work happens in each visitor's browser, so large video or PDF jobs depend on the speed and memory of the computer or phone being used.

OmniTools is a free, open-source set of 128 everyday online tools you can self-host, used in place of ad-funded sites like iLovePDF, Smallpdf or image compressors. On one web address you can merge and split PDFs, compress and resize images, trim videos, make GIFs, clean up text and lists, and format JSON and CSV data.

Every tool runs in the visitor's own web browser, so files are never uploaded to the server or to anyone else's website. There are no ads, no accounts and no daily limits. A small travel agency, for example, could shrink tour photos for its website, merge a customer's booking confirmations into one PDF and trim a short video for social media, without sending any of them to a tool site.

Be aware of the limits. The PDF tools cover the basics only; for converting Office files, OCR or signing, Stirling PDF is the better choice. Big video jobs depend on the speed of your own computer, and a few tools need an internet connection the first time you use them. OmniTools is a young project, so some tools are simple.

Cloudgate installs OmniTools on a server Cloudgate provides or one you connect and gives it a secure web address. Anyone with the address can use it, so share it only with the people who should.
