  - q: Is MyBB a good alternative to XenForo?
    a: Yes, if you want a classic message board with no licence to buy. MyBB has boards, threads, private messages, permissions and moderation tools, but it looks older than XenForo and help comes from volunteers rather than a paid support team.
  - q: Can I move my forum from vBulletin, XenForo or Invision Community to MyBB?
    a: Yes, partly. It is a separate tool, so plan the move with someone comfortable running it.

MyBB is free, open-source forum software you can host yourself: a classic message board with boards, threads, private messages and moderation tools, and a free alternative to paid forum software such as XenForo, vBulletin and Invision Community. There is no licence to buy or renew.

You arrange your forum into categories and boards, decide which member groups can read or post in each, and run everything from one Admin CP. Moderators can tidy up many threads at once, warn members and deal with reported posts. A cycling club, for example, could keep announcements, Saturday ride plans, repair questions and a buy-and-sell board in one place on its own web address, instead of in a crowded mailing list.

MyBB has been developed by volunteers since 2002. Hundreds of free community plugins and themes add features or change the look, and translations cover more than 30 languages. There are no phone apps; members use the forum in their browser. If you are moving from another forum, MyBB's free Merge System can import from XenForo, older vBulletin versions, Invision Power Board, phpBB and others.

Cloudgate installs MyBB on a server Cloudgate provides or one you connect, together with its database, and gives it a secure web address. Sign in as admin, add your email server and create your first boards.
