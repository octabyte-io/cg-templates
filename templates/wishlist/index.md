Wishlist is a free, self-hosted wish list app where your family or friends share gift lists and claim presents, an alternative to Giftster, Elfster and Amazon wish lists. Each person keeps a list of things they'd like, from any shop, and everyone else can see it and claim a gift so two people don't buy the same thing. The person whose list it is doesn't see the claims, so the surprise holds.

A family could set it up before the holidays: the grandparents open each grandchild's list, see that the paint set is already claimed, and pick the roller skates instead. Parents can add ideas to a child's list, and a group of friends can keep its own lists apart from the family's. For a wedding or a new baby, Registry mode gives one list a public link that guests can claim from without signing up.

Wishlist works in any web browser and can be installed on a phone's home screen. It has no ads and no shopping links. Cloudgate installs it on a server Cloudgate provides or one you connect, gives it a secure web address, and the first person to open it creates the admin account.
